# Research workspace

“DN Research” is a placeholder name, not the final product name. The team still needs to come up with and agree on a name; this is tracked in the [naming backlog item](../plans/backlog.md#name-01--choose-a-product-name).

A quiet, precise scientific instrument. The investigation tree is the main work surface; selecting an agent reveals its recorded activity and experiments. Inspired by David's design research, built independently of the previous DNHacks UI.

Use IBM Plex Sans and Mono, mineral charcoal surfaces, warm readable text, muted sea-green selection, amber uncertainty and rose failures. Thin dividers structure content; rounded corners distinguish controls from major panes. No decorative gradients, glass, neon, metric banners, fake telemetry or marketing sections. The tree owns the visual emphasis: generous spacing, deliberate branching, compact readable agent cards, clear selected ancestry.

Navigation describes user tasks: Forecast, Investigations, Library, Evidence, Structures. Developer identifiers and raw payloads belong in disclosures. A stopped trace is not automatically complete, a candidate is not a confirmed discovery, and missing measurements are never zero. Structures loaded by the user are reference geometry, never implied experiment results.

Motion describes changes: selected panel transition, newly received activity, live status. Respect reduced motion. Maintain keyboard navigation, clear focus, dark/light themes and narrow-screen detail access. Inspect real browser screenshots throughout; verify populated, empty, error, disconnected, and reduced-motion states.

Forecast is the prepared hackathon entry at `/#forecast`. Its dated scientific graph is the primary surface: fixed positions across evidence revisions, linked ranked recommendations, explicit later-evidence reveal, and in-place citations. Solid source claims, dashed forecasts, and unverified model hypotheses retain distinct meanings. Recorded model memory has a separate flat/static/evolving comparison. Missing comparison metrics stay unavailable; illustrative replay carries no measured scorecard.
