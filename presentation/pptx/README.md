# Judge deck (PowerPoint)

`dnhacks-deck.pptx` is generated by `build_deck.py`. Edit the script, not the .pptx, so the deck
stays reproducible and every number keeps its source in the notes.

```bash
python3 presentation/pptx/build_deck.py        # needs python-pptx (system python has it; the uv venv does not)
```

Preview without PowerPoint: `soffice --headless --convert-to pdf presentation/pptx/dnhacks-deck.pptx`.

## What it is

Twenty-two 16:9 slides in the product's own visual system (`frontend/DESIGN.md`, `frontend/src/styles.css`):
IBM Plex Sans / Mono, mineral charcoal, sea-green selection, amber uncertainty, rose failure, thin
dividers, no gradients. Install IBM Plex on the presenting machine (free, OFL:
https://github.com/IBM/plex) or PowerPoint will substitute.

- Slides 01–19 are the talk; 20–22 are appendix (criteria map, prepared answers, the archived
  sealed-cutoff backtest).
- Every slide carries a provenance tag: **MEASURED** (computed from committed artifacts),
  **IMPLEMENTED** (in main, tested), **PLANNED** (in `plans/`, not built), **ILLUSTRATIVE**
  (shape only). Change a tag only when the slide's content changes status.
- The speaker script for each slide is in its notes, with timings for a five-minute slot and the
  source file for every number.
- `dtx_context.json` holds the verified NSCEB quotation and the DTX Ventures thesis line used on
  slide 16; keep the verification note there current.

## Framing decisions baked in

- Product direction follows `ARCHITECTURE.md` (discovery loop with falsifier and human gate), and the
  audience framing follows Rich's note in `plans/PLAN-demo-slides.md` (non-bio crowd; lead with the
  idea; define every term; one story, not a tour; honest about what "survived" means).
- The forecasting backtest from `design/judge-brief.md` was removed from main in `880cac4`, so it
  appears only as appendix C, labelled archived, with the reconciliation caveats in its notes.
- Do not say: "predicts discoveries", "AI scientist", "novel algorithm", "first in the world".
