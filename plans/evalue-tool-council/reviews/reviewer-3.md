# Independent reviewer 3

Independent recommendation, before seeing other reviewers. Parent-edited summary of returned proposal.

Ranking: **functional dependency mapping → protein/phosphosignaling analysis → pharmacotype mapping**. Metabolic vulnerability mapping is fourth.

The first tool learns multigene knockout phenotypes, associates molecular programs with vulnerabilities, retrieves related models and supplies development target rankings. It fits the corpus's division/stress/functional focus. The default hypothesis is molecular-state/dependency-representation independence within a specified population or defensible exact stratum. Each increment consumes two genuinely fresh donor-derived models. Guides, genes, technical screens and repeat releases are not additional units. Train profile representations outside confirmation. Chronos joint fitting and scarce PDAC models are potentially fatal issues, not merely caveats.

The proposed native association factor uses a bounded witness c(x,y) in [-1,1]:

    h = (c(x1,y1) + c(x2,y2) - c(x1,y2) - c(x2,y1))/4
    W_next = W * (1 + lambda*h), with predictable 0 <= lambda <= 0.9

Under independent identically distributed fresh units and X independent of Y, all four terms have the same conditional expectation. Thus h is centered and bounded, yielding a nonnegative martingale. The whole contrast is one factor. The existing antisymmetric two-sample construction is another supported route for independent-group distributional hypotheses. No p-to-e calibration is required in either native route.

Proteomics supports protein/module comparisons and cross-omic discordance. CPTAC's 140 cancer cases include 135 PDAC; paired normals cannot be fed to the independent-group API. Learn modality-specific encoders with frozen identifiers, transformation, missingness and scaling. TMT/reference coupling, missing-not-at-random sites, purity and labels defined from the tested features can defeat interpretation or conditioning. It does not automatically infer kinase activity.

Pharmacotypes represent full registered dose/drug/time response profiles, preserving information beyond AUC. Associate those profiles with molecular state through the native two-donor kernel. Tiriac pharmacotyping counts cultures, including repeated patient origins, rather than independent donors. The tool does not establish synergy or clinical benefit. Shared controls, inconsistent coverage and cell-line/organoid domain shift require audits.

Metabolic reserve: CCLE reports 928 cell lines and 225 metabolites. Cross-model metabolite/functional association could fit nutrient/redox questions, but eligible PDAC overlap and shared imputation are unverified; metabolite abundance is not flux.

Reuse queue, registries, non-pickle artifacts, donor mapping, replay, provenance and the past-only numerical schedule. Keep conventional endpoint implementations as baselines/preparation components. Add actual modality representations, native independence betting, useful development artifacts and distinct private confirmation records. Do not turn biological evidence into branch-future-success evidence or multiply overlapping experiments.
