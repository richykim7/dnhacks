# Independent reviewer 2

Independent recommendation, before seeing other reviewers. Parent-edited summary of returned proposal.

Ranking: **proteomic/phosphosignaling experiments → functional vulnerability-program experiments → pharmacotype association**. Donor-level cellular ecology is a reserve option.

Proteomics ranks first because it adds an important measurement layer and has a verified substantial PDAC source: 135 PDAC tumors within CPTAC's 140 pancreatic cancers. Its 67 adjacent normals are paired, not a fresh independent control arm. Learn a frozen masked protein/phosphosite encoder and a past-only witness; test equality of registered measured representations between independent patient groups. Offer development module maps, protein/site contributors and protein-versus-phosphosite comparisons. External CPTAC cohorts are candidate training sources, but the exact eligible cross-cohort intersection is unverified. Balanced groups are needed for the current 48-pairs default. TMT fitting, missingness, purity and circular subtype labels are major threats.

Functional vulnerability tools extend one deletion/one-gene tests to multigene dependency programs, model retrieval and target-panel hypotheses. Train masked profile representations on disjoint non-PDAC models; test measured-program distribution differences across frozen PDAC contexts. The official release page inspected listed 1,089 Broad CRISPR KO screens, which is not an independent PDAC-donor count. Actual PDAC eligibility is unknown. Shared Chronos fitting and repeated releases require special audit.

Pharmacotype tools learn molecular and complete dose-response representations. They offer response predictions, cross-resistance patterns and candidate compounds from development data. A native independence test compares matched against crossed pairings of two fresh donors; an odd bounded function of the four-term compatibility contrast supplies one update under response-swap invariance. This is a proposed extension of transformation betting, not an implemented kernel or arbitrary covariate-adjusted independence test. PRISM reports 4,518 compounds and 578 cell lines; Tiriac and Driehuis report organoid cultures with repeated patient origins possible. Drug coverage and unique matched donors need auditing.

Cellular ecology reserve: encode each donor's distribution/composition of cell states, not each cell as a unit. Peng has 24 tumor and 11 control samples; Moncada has six patients. These are more credible development sources than large confirmation streams.

Reuse private queue/registration/replay and preparation code. TPM encoders cannot accept Chronos effects, protein ratios or drug curves by pretending they are TPM. Useful development artifacts and private confirmation results need distinct interfaces. None of the three tools yet has a verified untouched PDAC confirmation cohort. GPU availability does not resolve that limitation.
